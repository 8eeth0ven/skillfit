# SeaLeap ASIN 生命周期广告规划

把有限预算放进仍有需求和利润空间的阶段。先区分生命周期类型与当前阶段，再选择流量动作。

## 输入

ASIN/父子体、站点、首次可售日、按日或周销售、价格/促销、广告与自然流量代理、库存中断、类目需求、竞品新旧品变化和贡献利润。

## 工作流

1. 固定时间轴并标记断货、抑制、价格和广告变化，避免把销售受阻误判为自然衰退。
2. 分别判断长/短生命周期、季节性、快速升降的需求特征。类型可叠加，站点和品类实例仅用于提出假设。
3. 用实际销售趋势、流量稳定性和竞争变化判断新品、成长、成熟或衰退；黄金窗口是待验证的需求阶段，不是统一的天数。
4. 新品阶段测试相关关键词、ASIN/类目和明确的价值点；将关键词流量与商品流量分别计算，选择能够支持利润的入口。
5. 成长阶段从有效词扩展到商品目标，从有效商品目标寻找相关词或交叉需求，保留相同口径的对照。加价或位置测试先计算最高承受成本。
6. 成熟阶段验证低成本探索、品牌/长尾与交叉购买；确认需求衰退时评估库存退出和新品接力，避免用更高预算掩盖生命周期问题。

## 交付

生命周期类型与阶段、销售轨迹及干扰标记、黄金窗口假设、流量测试矩阵、阶段预算草案、成功/停止/退出条件与复查时间。

## 证据与执行范围

- 材料中的案例、比例和时间表标为 `COURSE_BASELINE` 或 `TRAINING_CASE`；来源与口径已核验的店铺数据标为 `ACCOUNT_FACT`，用户转交但未核验的数据标为 `USER_PROVIDED`，合成练习标为 `SIMULATED`。推断标为 `HYPOTHESIS`，缺失项写 `UNKNOWN`，不补成 0。
- 先固定店铺、广告 profile、站点、ASIN、币种、数据窗口与归因口径。课程介绍的资格、界面、报告字段和功能覆盖在实际使用时核验。
- 默认交付诊断与草案。真实写入只在当前会话已授权的对象、动作和预算内执行，并保存旧值与回读结果；新增范围先取得授权。
