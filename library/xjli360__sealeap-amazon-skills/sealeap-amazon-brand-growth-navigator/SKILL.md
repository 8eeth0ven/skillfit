# SeaLeap 亚马逊品牌成长导航

先定位品牌的主要约束，再分配页面、广告效率、品牌触达和多站点扩展任务。阶段判断以现状证据为准。

## 输入

品牌/站点范围、商品线与阶段、页面质量、访问及转化、广告和总销售、贡献利润、新客/复购、库存、团队资源、现有广告类型及品牌工具资格。

## 工作流

1. 用四阶段目标与当前约束进行定性匹配：筹备侧重页面基础，启动侧重早期有效销量，成长侧重效率与规模，拓展侧重份额与渠道。存在多条产品线时分别判断。
2. 选一个当前主要痛点及相应主指标。记录数据来源、定义、窗口和基线；不把材料的 10 维、70+ 指标描述拼成未经公开的官方评分公式。
3. 筹备阶段优先事实完整、消费者场景及本地化页面；启动阶段先改善 SP，再用表现证据筛选 SB/SBV 候选。
4. 成长阶段按认知、考虑、购买和忠诚选择必要触点，不要求每个广告类型全部开启。
5. 拓展阶段先修复现有低效花费，再评估品牌防守、品类触达和新站点。新站点重新核对市场、履约、利润及本地化。
6. 给出阶段行动和迁移条件，按单变量实验检验；将页面、价格、库存变化作为解释因素保留。

## 交付

阶段与证据矩阵、主要痛点、目标与指标字典、选用/暂缓的广告触点、预算分配草案、验证及进入下一阶段的条件。

## 证据与执行范围

- 材料中的案例、比例和时间表标为 `COURSE_BASELINE` 或 `TRAINING_CASE`；来源与口径已核验的店铺数据标为 `ACCOUNT_FACT`，用户转交但未核验的数据标为 `USER_PROVIDED`，合成练习标为 `SIMULATED`。推断标为 `HYPOTHESIS`，缺失项写 `UNKNOWN`，不补成 0。
- 先固定店铺、广告 profile、站点、ASIN、币种、数据窗口与归因口径。课程介绍的资格、界面、报告字段和功能覆盖在实际使用时核验。
- 默认交付诊断与草案。真实写入只在当前会话已授权的对象、动作和预算内执行，并保存旧值与回读结果；新增范围先取得授权。
