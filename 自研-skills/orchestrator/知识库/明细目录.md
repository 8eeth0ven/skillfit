# 明细目录（知识库节级索引）

用法：从 SKILL.md 短表跳来 → 按下表开对应篇的对应节。**只开命中篇的命中节，禁止通读**。
本知识库只有两篇明细，没有更深层级；找不到对应节就回 SKILL.md 重查短表。

## 拓扑选择.md（拆分前读）

| 节 | 一句话内容 | 何时开 |
|----|-----------|--------|
| §1 拓扑判定表 | 五种拓扑（直做/流水线/fan-out/map-reduce/递归拆分）按依赖数·写冲突·上下文体量三问判定，附判定顺序与反模式 | 接任务定拆法时 |
| §2 DAG 构建法 | 列子任务 → 标依赖 → 分层，三步成图；层内并行、层间串行的下发规则 | 任务有混合依赖时 |
| §3 并行度定法 | IO 密集 / CPU 密集 / API 限流三类各自公式、上限与动态调整 | 下发前定并发数时 |
| §4 失败处置 | 重试/切片/降级/放弃四级阈值表 + 硬规则（连续 2 败必换方式） | subagent 失败或超时时 |
| §5 长尾再拆分 | 超均值 2 倍即拆的判据公式 + 按输入切/按阶段切/不可切三种拆法 | 只剩一个拖尾任务时 |

## prompt工程.md（下发前读）

| 节 | 一句话内容 | 何时开 |
|----|-----------|--------|
| §1 prompt 模板 | 五要素下发模板（直接抄）+ 逐项正反例 + 填好的完整实例 | 每次下发前 |
| §2 上下文压缩 | 主线程只收 ≤200 字三段式摘要；数据给路径不给内容；压缩自检清单 | 定产出格式时、收超长回复时 |
| §3 幂等与断点 | 台账格式与示例、锁粒度（产物文件级/进程级）、断点续跑规则 | 长批任务启动前、重启前 |
| §4 结果聚合 | 表格合并 / 冲突检测 / 交叉验证双评 / 抽样复核四种模式与选择 | 收齐结果后 |
| §5 常见翻车表 | 重复探索/写冲突/静默失败/上下文溢出/层间抢跑/假完成：症状→病因→防法 | 翻车对症状排查时 |

## 与 SKILL.md 的关系

- SKILL.md 短表 = 路由层（场景 → 动作 → 节号），执行纪律与验收口径也在 SKILL.md
- 本目录 = 节级索引，短表没写全或记不清节号时来查
- 两篇明细 = 展开层（表格、公式、模板、实例）
- 明细内容与 SKILL.md 冲突时，以 SKILL.md 执行纪律为准
