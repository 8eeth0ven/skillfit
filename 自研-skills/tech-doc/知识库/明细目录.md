# 知识库明细目录

tech-doc 的知识库索引。SKILL.md 路由到篇，本表路由到节。**只开命中篇的命中节，禁止通读。**

## 文件清单

| 文件 | 覆盖 | 一句话 |
|------|------|--------|
| README五问.md | README 与一切说明书型文档 | 五问框架、逐问正反例、结构模板、排版规则、时间精度、体检清单 |
| API与架构文档.md | API 文档、架构文档、ADR、changelog | API 模板与幂等标注、架构四件套、ADR 四段式、changelog 六分类、防腐三件套 |

## README五问.md 节索引

| 节 | 何时开 |
|----|--------|
| 五问框架总表 | 从零写 README，先定骨架 |
| 逐问正反例 | 某一问写不动或写歪，看正反例对照 |
| 结构模板 | 需要 badge 行、三问三答表、details 折叠、结构树、Roadmap、致谢差异表现成片段 |
| 排版规则表 | 标题层级、表格规模、emoji、列表嵌套有争议 |
| 时间精度场景表 | 拿不准时间写到年月日还是年月 |
| 体检清单 | 改旧 README，逐项打勾 |
| 降维用法 | 写技术报告、交付说明书 |

## API与架构文档.md 节索引

| 节 | 何时开 |
|----|--------|
| API 文档模板 | 写或审接口文档（endpoint/参数/错误码/curl/幂等） |
| 架构文档模板 | 写系统或模块架构说明（组件图/数据流/依赖/故障域） |
| ADR | 记录一次选型、重构、取消的技术决策 |
| changelog 规范 | 起草、补写或规范化更新日志 |
| 文档腐化防护 | 文档过时、断链、与代码脱节的治理 |

## 使用规则

1. 命中多节时按文档类型一次读够全部命中节，不反复进出。
2. 两篇都命中 → 以主文档类型开篇，另一篇只开对应模板节。
3. 知识库示例中的版本号、链接、数字均为格式示例，使用时必须替换为当前真实值。
