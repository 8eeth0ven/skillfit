# office-flow：办公与文档处理

**一句话定位**：文件级的批量操作找工具矩阵对号入座，先备份原件、批量先试 3 条、转换必抽查保真。

## 必读短表

| 场景 | 动作 | 开哪节 |
|---|---|---|
| 要读/写/批量改 docx·xlsx·pptx | 查工具矩阵对号入座 | 知识库/三件套自动化.md §1 |
| Excel 公式读出来是空的/日期变数字 | dtype/公式值陷阱 | 知识库/三件套自动化.md §2 |

| 做简历 | 信息采集→一页化→量化改写→ATS 检查 | 知识库/PDF与求职文档.md §4 |

## 执行纪律

1. **动格式先备份**：任何写操作前 `cp 原件 原件.bak`，批量跑完抽查无误再删 .bak
2. **批量先试 3 条**：全量前抽 3 个文件跑通完整链路（读→改→写→抽查），再放全量
3. **转换必抽查**：转换后随机抽 2-3 份对照原件（文本完整性/表格结构/图片），保真不达标换工具
4. **公式 vs 值分清**：openpyxl 读不到公式计算值是特性不是 bug（§2 有三路解法）
5. **敏感文档不外传**：合同/简历/发票不进任何在线转换服务，一律本地工具
6. **产物落盘结构固定**：输出目录 + 台账（处理了什么/成功几个/失败清单）

## 产物约定

