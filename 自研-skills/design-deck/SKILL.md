# design-deck：设计与演示

**一句话定位**：把"做个 PPT / 海报 / 图表"落成可直接执行的视觉规范 + 逐页内容——色值、字体名、像素、结构模板全部给死，禁止输出"要有美感"式空话。

## 开工首步：三问一断

| 问 | 答案用途 | 缺省（用户没说时） |
|----|---------|-------------------|
| ① 对谁讲（观众） | 决定语言密度与字号下限 | 管理层 / 甲方 |
| ② 多长时间 | 决定页数：总页 ≈ 分钟 ÷ 1.5 | 10 分钟 ≈ 7 页 |
| ③ 投屏讲还是发文件自读 | 投屏：字大图少、口播进备注；自读：密度可高、不要备注 | 投屏讲 |

一断：三问拿不到答案不许空转——按缺省开工，并在产物开头注明所用缺省。

## 必读短表（先命中场景，再开对应节；禁止通读知识库）

| 场景 | 动作 | 开哪节 |
|------|------|--------|
| 从零做 PPT/汇报 | 定结构 → 逐页改稿 → 数据页 → 备注 | 演示构建 §1→§2→§4→§5 |
| 稿子乱/字太多要改 | 信息密度判定表 → 拆页或删 | 演示构建 §2 |
| 标题没劲/念不通 | 结论式标题对照改写 | 演示构建 §3 |
| 定配色/做色板 | 色板生成公式 → 60-30-10 → 色盲校验 | 视觉速查 §1 |
| 选字体定字号 | 配对表整行取 → 字号阶梯 | 视觉速查 §2 |
| 排版布局 | 8pt 网格 → 对齐优先级 → 视觉重心 | 视觉速查 §3 |
| 海报/社媒图/logo | 尺寸表 → 网格 → 重心 | 视觉速查 §3、§4 |
| 图表页 | 取色顺序 → 直接标注法 | 视觉速查 §5 |
| 数据页/成绩页 | 大数字+对比+注释三件套 | 演示构建 §4 |
| 交付前自查 | 翻车表逐行过 | 演示构建 §6 |

## 路径（按任务大小二选一）

| 路径 | 适用 | 步骤 |
|------|------|------|
| 全流程 | 从零新建 deck / 海报 | 三问 → 结构清单 → 色板字体规范 → 逐页内容 → 翻车表自查 |
| 轻改稿 | 只改配色/字体/某几页 | 直接开对应节 → 按产物约定第 4 条交付 |

## 执行纪律（五条全硬性，违反任一即停下重做）

| # | 纪律 | 合格标准 | 反例（禁） |
|---|------|---------|-----------|
| 1 | 先问观众与场合 | 见"开工首步"三问，答不上用缺省并注明 | 没问就排页面 |
| 2 | 一稿一主题 | 全稿一句核心论点（SCQA 的 A），每页都为它服务 | 一份 deck 塞三个主题 |
| 3 | 字体 ≤2 种 | 标题 1 + 正文 1，从视觉速查 §2 整行取；等宽只给数字，不计入 | 中途引入第 3 种字体 |
| 4 | 色板定死再动手 | 先交"色板表"（HEX+档位+用途+占比）再排版，中途不换色 | 边排版边试色 |
| 5 | 留白优先 | 先删到删不动，再想加图；页面正文 ≤30 字 | 先填满再删 |

## 术语速对（黑话 → 本 skill 含义）

| 术语 | 含义 |
|------|------|
| 色板档位 | 同一色相按明度分的 50/100/300/500/700/900 六档（视觉速查 §1） |
| 结论式标题 | 可单独念出完整判断的标题（演示构建 §3） |
| 三件套 | 数据页的大数字 + 对比 + 注释（演示构建 §4） |
| 直接标注 | 删图例、系列名直接标在数据旁（视觉速查 §5） |
| 8pt 网格 | 所有间距尺寸取 8 的倍数（视觉速查 §3） |

## 产物约定（按序交付，缺哪项补哪项）

| 序 | 产物 | 形态 |
|----|------|------|
| 1 | 结构清单 | md 表：页码｜结论式标题｜页面元素（大数字/图表/图文） |
| 2 | 视觉规范表 | 色板（HEX+用途+60-30-10 占比）｜字体对｜字号阶梯｜网格页边距 |
| 3 | 逐页内容 | 标题 + 正文（≤30 字）+ 图表规格 + 演讲备注（三段式） |
| 4 | 改稿任务 | 只交改动页清单 + 改前改后对照，不重发全稿 |

## 边界（这些不进本 skill 的设计流程）

| 请求 | 处理 |
|------|------|
| 只转格式/批量导出 pptx | 直接用工具处理，不进设计流程 |
| 纯数据可视化编程（matplotlib/echarts 代码） | 只借视觉速查 §5 取色规则，其余按代码任务做 |
| 长文档排版（Word/报告/说明书） | 用 documents 相关 skill，不套 deck 结构 |

默认值：PPT 1920×1080（16:9）；海报 A3 竖版 3508×4961 @300dpi；社媒图查视觉速查 §4。
产出文件落任务目录，命名 `{主题}_{YYYYMMDD}_deck.md`（或 .pptx）；色板表可单独存 `{主题}_色板.md` 复用。
