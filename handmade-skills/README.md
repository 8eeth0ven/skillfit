# SkillFit 自研技能

这里收录随 SkillFit 分发的 11 个自研技能。每个目录的 `SKILL.md` 说明适用任务，并指向 `kb/` 中对应的知识条目。

![选择任务后先读 SKILL.md，再打开需要的知识条目](../docs/assets/guide-skills.svg)

| 想完成的任务 | 可以从这里读 |
| --- | --- |
| 检查数据并解释结果 | [数据分析](data-analyst/SKILL.md) |
| 编写项目文档和演示稿 | [工程文档](tech-doc/SKILL.md) · [演示设计](design-deck/SKILL.md) |
| 审查代码质量或分配工作 | [代码质量](code-quality/SKILL.md) · [任务编排](orchestrator/SKILL.md) |

要纳入评测，先为技能写一项有可核对结果的任务，再对照仅给任务的结果。[任务样例](../example-tasks/format-check/) · [全库目录](../SKILLS.md)
