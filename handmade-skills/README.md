## 设计规范（全部共守）

1. **SKILL.md ≤110 行**：frontmatter（name + description 含触发词）+ 一句话定位 + 必读短表（场景|动作|开哪节）+ 执行纪律 + 产物约定
2. **知识库每文件 100-220 行**：表格优先，代码样例 ≤8 行，细节可查证（函数名/默认行为/CVE 编号必须准确）
3. **按需开节**：明细目录是唯一总索引，先定位再开文件，禁止通读
4. **产物落盘**：每次执行产出固定结构的文件（清单/台账/报告），不靠对话回传
5. **纪律可执行**：每条纪律都是可判定的动作，不写"注意安全"这类空话
6. **授权边界**：安全类 skill 内置授权语境声明，只用于用户拥有/授权的目标

## 复制使用

```bash
cp -R 自研-skills/<name> ~/.zcode/skills/   # 放进 agent 技能目录即生效
```
