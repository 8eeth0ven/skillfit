## 速查：两篇怎么选

- **能找到出数据的 HTTP 接口** → 全程只需要 接口优先法.md
- **接口找不到/拿不到（渲染才出、虚拟列表、盾）** → 渲染与反爬.md §1 判定树开路，拦到接口后回 接口优先法.md
- **两类都不命中**（纯静态 HTML 表格）→ 直接 `curl` + `rg`/BeautifulSoup，不需要知识库
- **周期性重采、只要新增/变更** → 渲染与反爬.md §5（去重与增量），翻页细节回 接口优先法.md §3
- **任务中断/要断点续跑** → 不开知识库，直接看 SKILL.md「产物约定」的 state.json 格式
