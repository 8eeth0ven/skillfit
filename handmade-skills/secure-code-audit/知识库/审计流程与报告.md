# 审计流程与报告

> 何时开本表：刚拿到代码库（从 §1 开始顺走）；已找到 sink 要回溯定性（跳 §3）；要出报告（跳 §5）。

## §1 三分钟画地图（不读完代码）

| 动作 | 命令/方法 | 产出 |
|---|---|---|
| 定栈定框架 | 看依赖清单（pom/composer.json/requirements.txt/go.mod/package.json） | 栈名+框架名+版本 |
| 找入口 | `grep -rn "Router\|@app.route\|HandleFunc\|Controller\|@RestController"` 按栈选 | 路由清单 |
| 找中间件 | 鉴权/日志/CORS 过滤器、装饰器、中间件目录 | 鉴权覆盖图（哪些路由裸奔） |
| 找数据层 | ORM 配置、DB 客户端初始化、缓存、消息队列 | sink 高发区清单 |
| 找配置 | application*.yml / .env / config.* 中的密钥与开关 | 弱配置清单 |

**产物**：对象图.md（入口→中间件→数据层，标注鉴权覆盖与高危区）。地图完成前禁止钻单个函数。

## §2 挑肥面（优先级序）

1. **无鉴权路由上的 sink**（入口即命中）
2. **鉴权后但跨租户可达**（对象级鉴权缺失）
3. **管理后台面**（高危功能密集：导入导出/模板/定时任务）
4. **反序列化与模板**（一处命中直接高危起步）
5. 文件上传/下载、支付/订单金额逻辑、回调接口

瘦面（纯静态展示、纯前端逻辑）一眼扫过即走，不恋战。

## §3 污点链判定（一条链一张卡）

```
source（哪个入口参数）
  → 传播（赋值/拼接/容器传递/持久化后二次取出[存储型]）
  → 过滤点（逐个列：函数名 + 黑/白名单 + 编码）
  → sink（函数 + 调用条件）
  → 利用前提（鉴权？路径可达？特定配置？）
```

**过滤强度口径**（证伪优先）：

| 过滤形态 | 强度 | 证伪方向 |
|---|---|---|
| 参数化查询/预编译 | 强 | 只查 ORDER BY/表名/列名拼接位 |
| 白名单映射（id→常量表） | 强 | 查映射表是否可被用户输入扩充 |
| 黑名单替换（str_replace/addslashes/正则 ban） | 弱 | 大小写/编码/嵌套/等价字符绕 |
| 仅前端/仅文档约定 | 无 | 直接打 |
| 类型转换 (int) | 中 | 查转换失败时的回退值 |

**可达性三问**：路由注册了吗？鉴权拦得住目标角色吗？默认配置开这个功能吗？三问有一个"否/不确定"→ 线索.md 记"疑似"，不进报告。

## §4 鉴权矩阵（sink 之外的独立检查）

| 检查项 | 方法 | 常见缺陷 |
|---|---|---|
| 路由级 | 对照中间件覆盖图找裸奔路由 | 新增接口忘了挂鉴权中间件 |
| 角色级 | 同一接口用两种角色重放 | 管理接口只查了登录态没查角色 |
| 对象级 | 换 id/uuid 重放（不限于叫 id 的字段：orderNo/email/hash） | ORM 查询缺 user_id 过滤 → 水平越权 |
| 租户级 | 跨租户 id 重放 | 缓存键/查询缺 tenant 维度 |
| 功能级 | 敏感操作二次校验（改邮箱/转账） | 只前端弹确认框 |

## §5 报告两张表（唯一格式）

**表一 · 漏洞总表**

| # | 标题 | 类型 | 位置（文件:行） | 等级 | 利用前提 | 修复方向 |
|---|---|---|---|---|---|---|

**表二 · 复现明细**（每条漏洞一小节）

```
### VULN-<n> <标题>
影响面：接口/功能 + 角色
污点链：source → … → sink（§3 卡片原文）
复现步骤：1) 请求（可重放的完整请求，脱敏后）2) 预期 3) 实际
证据：响应片段/落库截图（只贴证明部分）
修复建议：具体到函数层（用参数化/白名单/删接口），给验收方式
```

**分级口径**（简化，写等级时对照）：

| 等级 | 特征（满足其一） |
|---|---|
| 严重 | 未授权 RCE / 未授权 SQL 拿数据 / 认证绕过 / 云凭证泄露 |
| 高危 | 需登录的 RCE、SQL 注入、任意文件读写、存储型 XSS 打管理员、反序列化 |
| 中危 | 反射 XSS、SSRF 可打内网、水平越权（非核心数据）、CSRF 敏感操作 |
| 低危 | 信息泄露、缺安全头、弱 CSRF token——**合并一条报，不单列** |

## §6 收尾自检

- [ ] 每条漏洞的链三段（source/传播/sink）都有代码行号
- [ ] 每条都能被别人按复现表独立重放
- [ ] 低危已合并、疑似已剔除或标注前提
- [ ] 修复建议可验收（不是"加强过滤"这种空话）
