# data-analyst：拿数据出结论

数据到手先体检、口径先对齐、结论必带样本量。本文件只做路由，细节全在 `kb/` 按需展开，禁止通读。

## 必读短表（场景 | 动作 | 开哪节）

| 场景 | 动作 | 开哪节 |
|------|------|--------|
| csv/表/df 首次接触 | 三板斧体检，不先下任何结论 | data-checkup.md §1 |
| id 变 float、日期是字符串、列像乱码 | 查 dtype 陷阱表逐条排 | data-checkup.md §2 |
| 列里有 NaN | 按决策表三选一：删/填/标记 | data-checkup.md §3 |
| 要 groupby / 汇总 / merge | 先验粒度与主键 | data-checkup.md §4 |
| 金额为负、数字大得离谱 | 异常值三法选一 | data-checkup.md §5 |
| 数据带时间戳 | 时区/缺失时段/重复时间戳 | data-checkup.md §6 |
| 想说「A 比 B 好」「X 带动 Y」 | 过结论检查单 | conclusions-and-charts.md §1 |
| 算 DAU/留存/转化率/ARPU | 先对齐分母口径再动手 | conclusions-and-charts.md §2 |
| 要画图 | 按目的查选型表，先选型再写代码 | conclusions-and-charts.md §3 |
| 长表宽表互转、分箱、merge | pandas 惯用式速查 | conclusions-and-charts.md §4 |

## 流程总览（5 步，顺序不可换）

1. **体检**：三板斧跑完 → dtype 陷阱排除 → 缺失/重复/粒度定案（§1–§6）
2. **口径**：指标分母是谁、时间窗怎么切、过滤条件是什么，写进笔记本再算
3. **分析**：聚合 → 分组对比 → 分位数，代码用惯用式（conclusions-and-charts.md §4）
4. **图表**：先选型（§3）再美化（§5），读者不同标准不同
5. **结论**：过检查单（§1），落结论表，带样本量与置信度

## 执行纪律（违反任何一条，结论作废）

1. **先看 dtype/缺失/重复，再谈结论**：没跑过体检三板斧的 df，禁止输出任何统计数字。
2. **任何聚合先问分组键基数**：groupby 前先对分组键 `nunique()`；基数 <5 或 >10 万都要停下来想是不是键选错了、该不该再套一层维度。
3. **结论必须带样本量**：如「转化率 3.2%（n=41,207）」；n<30 的子群只写方向，不写百分比。
4. **图表先想读者是谁**：给自己看（EDA）可丑；给业务/领导看必须过美化最小集；标题写结论不写描述。
5. **长计算后台+增量落盘**：预估 >1 分钟的 groupby/绘图/全表扫描，后台跑、逐批写结果文件；禁止前台阻塞空等，等结果期间干别的活。
6. **改口径必须留痕**：过滤、剔除、填补每动一次，笔记本记一行「条件 | 影响行数」；口径改了但代码没同步 = 结论全废。

## 边界判定（三问，命中即不属于本 skill）

| 问题 | 命中后去哪 |
|------|------------|
| 是要给系统加统计功能（写代码实现），不是拿数据出结论？ | 归工程开发流程，本 skill 只做分析 |
| 是要建预测模型/训练，不是描述现状？ | 本 skill 覆盖到描述统计为止，建模只借 §3 缺失处置 |
| 数据还没拿到，要去采集/爬取？ | 先解决取数，本 skill 从「数据已在本地」开始 |

## 产物约定

每次分析任务产出三件套，缺一不可：

| 产物 | 位置 | 格式要求 |
|------|------|----------|
| 分析笔记本 | `{任务名}.md` | 问题→数据来源→步骤→代码→结论，另跑一遍能复现 |
| 图 | `fig/01-{含义}.png` | png、300dpi、按序号命名，一张图只讲一件事 |
| 结论表 | 笔记本末尾 md 表 | `结论 \| 依据(具体数字) \| 样本量 \| 置信度(高/中/低)` |

结论表写法示例（照抄这个格式）：

| 结论 | 依据 | 样本量 | 置信度 |
|------|------|--------|--------|
| A 渠道次日留存高于 B 渠道 8pp | 32% vs 24% | 1,203 / 987 | 中（分渠道后单格基数偏小） |
| 高价档退货率未见异常 | 2.1%（IQR 内） | 8,412 | 高 |

分析笔记本骨架（新建任务先落这个壳，边做边填）：

```markdown
# {任务名}
## 问题：要回答的业务问题（一句话，含时间窗）
## 数据：来源文件/表、行数、取数时间、已知过滤条件
## 体检：三板斧输出摘要 + dtype/缺失/粒度定案
## 口径：每个指标的分母与时间窗定义
## 步骤：每步一段代码 + 一行结果解读（代码可重跑）
## 结论表：（照上方格式）
```

禁止事项：只给图不给结论表；结论不带数字；百分比不带 n；「数据说明了问题」这类空话。
