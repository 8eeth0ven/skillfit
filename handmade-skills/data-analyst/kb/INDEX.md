# 明细目录：知识库按需展开

先在这里查「开哪节」，只开命中篇的命中节，禁通读。

## data-checkup.md（数据到手第一站）

| 节 | 何时开 | 一句话 |
|----|--------|--------|
| §1 三板斧体检 | 任何新数据的第一动作 | info/describe/nunique/null 计数，5 行代码出全貌 |
| §2 dtype 陷阱表 | id 变 int、日期是字符串、object 藏 mixed | 7 类陷阱的症状与修复代码 |
| §3 缺失值处置决策表 | 列里有 NaN，纠结删还是填 | 删/填/标记三选一的判定依据 |
| §4 重复与粒度 | groupby 或 merge 之前必开 | 主键判定 + 粒度预验，防聚合翻倍 |
| §5 异常值 | 金额为负、年龄 999 | IQR/z-score/业务上限三法适用表 |
| §6 时间序列体检 | 数据带时间戳 | 时区/缺失时段/重复时间戳三查 |

## conclusions-and-charts.md（要输出时才开）

| 节 | 何时开 | 一句话 |
|----|--------|--------|
| §1 结论检查单 | 想下「A 比 B 好」类判断 | 相关≠因果、辛普森、基数陷阱、幸存者偏差 |

| §4 pandas 惯用式 | 长宽互转/分箱/merge/窗口 | pivot/melt/cut/merge validate/rolling |
| §5 图表美化最小集 | 图要发给别人 | 轴标签/单位/样本量注释/色盲安全/标题写结论 |

## 使用规则

1. 命中多个节：按 §1→§6 / §1→§5 的编号顺序开，前面的结论影响后面。
2. 两篇都没命中：回 SKILL.md 重查短表，仍无命中说明不归本 skill 管（对照 SKILL.md「边界判定」）。
3. 节内代码可直接抄改，改完必须自验：行数对得上、dtype 没变、聚合守恒（见 data-checkup.md §4）。
4. 典型串联：新数据 = §1→§2→§3→§4；要交差 = conclusions-and-charts.md §1→§2→§3→§5。
5. 节内没有的场景：就近选最像的节，禁止凭空发明口径，拿不准在结论表把假设写进「依据」列。
