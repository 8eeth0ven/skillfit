# 视觉速查（design-deck 知识库）

色值、字体名、像素直接抄用。主色未定时先按 §1 生成色板；本文件与 deck-building.md 配合使用。

## §1 配色系统

### 1.1 色板生成法（给一个主色，产出全套）

主色用 HSV 描述。设主色 H=H0、S=S0%、V=V0%（例：#2563EB ≈ H221 S86 V92）。

**单色渐进（默认，最稳）**——H 固定，按档改 S/V：

| 档位 | S | V | 用途 |
|------|---|---|------|
| 50 | S0×0.25 | 97% | 页面底色 / 表格隔行 |
| 100 | S0×0.40 | 94% | 卡片底 / 高亮背景 |
| 300 | S0×0.70 | 75% | 次级图表系列 / hover |
| 500 | S0 | V0 | 主色：标题强调、主按钮、图表第一系列 |
| 700 | min(S0×1.1, 100) | V0×0.65 | 链接、次强调 |
| 900 | min(S0×1.2, 100) | V0×0.45 | 深色底（文字反白场景） |

明度差铁律：相邻档 ΔV ≥ 8%，否则人眼分不开，需拉开。

**类比色（和谐，图表 3 系列用）**：H0−30°、H0、H0+30° 三色。
**互补色（强对比，只给 CTA）**：主色 H0 + 强调色 H0+180°（强调色 S 降 20% 防刺眼）。
**三角色（少用）**：H0、H0+120°、H0+240°，仅海报可用，PPT 禁用。

### 1.2 60-30-10 法则

| 占比 | 角色 | 取色 |
|------|------|------|
| 60% | 背景 | 白 #FFFFFF / 暖灰 #FAFAFA / 深底用主色 900 档 |
| 30% | 次级 | 主色 100/300 档、灰 #6B7280 |
| 10% | 强调 | 互补色或主色 500，只给最关键元素（大数字 / CTA / 结论句） |

校验法：眯眼看页面，10% 的强调色应最先跳出来；跳不出来 = 占比超了或色相太近。

### 1.3 色盲安全组合（约 8% 男性红绿色盲，对外物料必查）

Okabe-Ito 八色（直接抄）：黑 #000000、橙 #E69F00、天蓝 #56B4E9、青绿 #009E73、黄 #F0E442、蓝 #0072B2、砖红 #D55E00、紫粉 #CC79A7。

| 规则 | 说明 |
|------|------|
| 禁 | 纯红 #FF0000 与纯绿 #00FF00 相邻或同图（红绿色盲视为同色） |
| 换 | 红绿对比 → 蓝 #0072B2 vs 砖红 #D55E00 |
| 补 | 颜色之外叠加形状差（实心/斜纹/空心）或直接标注数值 |

## §2 字体配对

### 2.1 配对表（按场景选一行，全稿只用这一行）

| 场景 | 标题 | 正文 | 说明 |
|------|------|------|------|
| 商务汇报（默认） | 思源黑体 Bold | 思源黑体 Regular | 开源可商用 |
| 科技/产品发布 | HarmonyOS Sans Bold | HarmonyOS Sans Regular | 大字重稳定 |
| 人文/文化/年度册 | 思源宋体 Bold | 思源黑体 Regular | 宋标黑文 |
| 政务/正式场合 | 方正小标宋（无版权改用思源宋体 Heavy） | 思源黑体 | |
| 英文现代风 | Montserrat SemiBold | Inter Regular | 数字也用 Inter |
| 英文编辑风 | Playfair Display | Source Sans 3 | 杂志质感 |

### 2.2 数字字体（等宽场景）

大数字 / 数据表 / 倒计时必须等宽（tabular figures），避免宽度跳动：

| 用途 | 字体 |
|------|------|
| 屏幕大数字 | DIN Alternate（macOS 自带）、JetBrains Mono |
| 数据表格 | IBM Plex Mono、Roboto Mono |
| 通用兜底 | Inter / 思源黑体 + `font-variant-numeric: tabular-nums` |

### 2.3 字号阶梯（1920×1080 PPT 基准）

| 层级 | 字号(px) | 行高 | 字重 |
|------|---------|------|------|
| 大数字 | 96-144 | 1.0 | Bold / Heavy |
| 页标题 | 40-48 | 1.2 | Bold |
| 卡片/小节标题 | 28-32 | 1.3 | Medium |
| 正文 | 24-28 | 1.5 | Regular |
| 注释/口径 | 16-18 | 1.4 | Regular 灰字 #6B7280 |
| 图表轴标签 | ≥18 | 1.2 | Regular |

铁律：投屏正文 ≥24px；小于 24px 的内容进演讲备注，不上页面。1280×720 画布按 ×0.67 换算。

## §3 排版网格

### 3.1 8pt 网格

一切间距与尺寸取 8 的倍数：8/16/24/32/48/64/96/128。

- 1920×1080：页边距 96px；1280×720：页边距 64px
- 内容区 12 栏，栏间距 32px；图文页文字块 7 栏 + 图 5 栏
- 标题区高 160px，正文区起点 y=256px；页脚注释线 y=1008px

### 3.2 对齐优先级（冲突时序号小者优先）

1. 左对齐：标题、正文默认左对齐（含封面标题）
2. 顶对齐：并排卡片 / 图文块先顶对齐
3. 数字右对齐：表格数字列右对齐、小数点对齐
4. 居中：只用于孤立元素（单标题 / 单大数字 / 封面），正文段落禁居中
5. 两端对齐：禁用

### 3.3 视觉重心

- 阅读 Z 路径：左上 → 右上 → 左下 → 右下；核心论点与 logo 放左上，CTA 放右下
- 图片中人物/箭头朝向文字侧，把视线引进内容
- 光学居中：视觉元素居中时整体上移 4-8px（数学居中会显下沉）
- 一页一个视觉焦点：大数字 / 图 / 表三选一，不并存

## §5 图表配色与直接标注法

### 5.1 图表取色

- 系列色顺序（默认）：主色500 → 主色300 → 主色700 → 强调色 → 灰 #9CA3AF
- 分类 >5 个：保前 4 类，其余合并"其他"（灰）
- 涨跌 / 好坏：涨 #009E73、跌 #D55E00（色盲安全）
- 轴线 #D1D5DB 1px；横向网格 #F3F4F6 1px 虚线；删外框、删纵向网格、删 3D 与阴影

### 5.2 直接标注法（默认删图例）

| 图型 | 标注位置 | 做法 |
|------|---------|------|
| 柱状 | 柱顶上方 8px | 系列名+数值直接写，柱内不写字 |
| 折线 | 线末端右侧 8px | 末端标系列名，关键点标数值 |
| 饼/环 | 扇区外侧引导线 | 类目+百分比；≤5 类才允许用饼图 |
| 条形 | 条末右侧 8px | 数值右对齐排成一列 |

标注字号 ≥18px；一张图只讲一个结论，结论写进页标题（见 deck-building.md §3），不写在图内。
