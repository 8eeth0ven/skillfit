# PDF 与求职文档

> PDF 先分层判定再选工具；简历走采集→一页化→量化→ATS 四步。

## §1 PDF 读取：先判文本层

```python
import pdfplumber
with pdfplumber.open("f.pdf") as pdf:
    t = pdf.pages[0].extract_text()
# t 为空或乱码 → 无文本层（扫描图）→ 走 §3 OCR
```

| 判定 | 特征 | 路线 |
|---|---|---|
| 有文本层 | extract_text 出正文 | pdfplumber 直读 |
| 无文本层 | 每页只有图片对象 | §3 OCR |
| 混合 | 部分页有 | 逐页判定分流 |

**表格提取**：

| 工具 | 适用 | 限制 |
|---|---|---|
| pdfplumber `extract_tables()` | 线框表格最准 | 无线框表格（仅空白分隔）弱 |
| camelot(flavor='lattice') | 线框表格，带页码坐标 | 同上，且需 ghostscript |
| camelot(flavor='stream') | 无线框 | 列切分靠猜，必抽查 |
| excel 输出 | — | `table.to_excel()` 直接落盘，抽查合并格 |

纪律：表格提取必抽查——随机抽 2 行与原 PDF 对照（数字/合并格/跨页续表三件）。

## §2 PDF 写：合并/拆分/水印/生成

```python
from pypdf import PdfReader, PdfWriter
r1, r2 = PdfReader("a.pdf"), PdfReader("b.pdf")
w = PdfWriter()
for pg in r1.pages + r2.pages: w.add_page(pg)     # 合并
w.add_metadata({"/Producer": "office-flow"})
with open("out.pdf", "wb") as f: w.write(f)
# 拆分：w.add_page(r1.pages[3]) 只取第 4 页
# 水印：先做水印层 pdf，循环 page.merge_page(watermark_page)
```

**生成三路选型**：

| 路线 | 适用 | 特点 |
|---|---|---|
| reportlab | 纯代码生成报表/发票 | 精确坐标控制，中文需注册 TTF：`pdfmetrics.registerFont(TTFont('cn','path.ttf'))` |
| weasyprint | HTML/CSS → PDF | 会前端的选手最优；分页用 `@page` 控制 |
| LaTeX | 论文/公式密集 | 保真最高，需装 TeX 环境，编译慢 |
| LibreOffice | docx/xlsx 先做再转 | 排版类文档推荐：编辑在 Office 格式做，PDF 只是交付物 |

## §3 OCR（扫描件路线）

| 步骤 | 工具 | 要点 |
|---|---|---|
| 1 转图 | `pdf2image`（需 poppler） | 300dpi 起点，低于必糊 |
| 2 OCR | `pytesseract`（chi_sim+eng） | 中英混合 `lang='chi_sim+eng'`；表格结构 OCR 后必手工修 |
| 2' 替代 | PaddleOCR | 中文场景准确率显著更高，带版面分析 |
| 3 落盘 | 文本+置信度一起存 | 置信度 <0.8 的行标黄人工过 |

降级预期：OCR 不承诺 100%，交付物注明"OCR 产物，关键数字已人工核对 N 处"。

## §4 简历与求职文档

### 4.1 信息采集清单（动笔前问全）

基础（姓名/联系方式/城市/期望）＋经历（每段：时间精确到年月/公司/角色/技术栈）＋量化素材（规模指标：QPS/用户数/金额/百分比/时长——没有就追问"大概多少"）＋目标 JD 原文（关键词对齐用）。

### 4.2 一页化规则

- 经历 ≤3 段每段 ≤5 条；只留与 JD 相关的 30%
- 模板选单栏 ATS 安全款（§4.4）；配色≤2、图标禁用（ATS 解析友好优先）
- 字号：正文 10.5pt、姓名 20pt；页边距 1.5cm 起步

### 4.3 量化改写对照表

| 原（动作） | 改（动作+规模+结果） |
|---|---|
| 负责后端开发 | 主导订单服务重构（日均 80 万单），接口 P99 从 900ms 降至 220ms |
| 优化了查询速度 | 对 3 张核心表建覆盖索引+缓存预热，列表接口 P95 快 4 倍 |
| 参与开源项目 | 为 X 维护 YY 模块，合并 PR 17 个，修复 23 个 issue |
| 写了很多文档 | 建立 API 文档规范，覆盖 46 个接口，新人文档 onboarding 周期 2 周→3 天 |

公式：**动词 + 对象 + 规模数字 + 结果数字**。没有结果数字就写范围/对比（"约"/"近"/"较此前"），禁止编造精确值。

### 4.4 ATS 友好检查单（投递前过一遍）

| 检查 | 标准 |
|---|---|
| 文件格式 | pdf（文本层！用 §1 验证能抽出文字，扫描版简历=直接出局） |
| 文件名 | `姓名-岗位-简历.pdf`，不放日期版本号 |
| 关键词 | JD 里出现的技术词，简历正文按真实水平覆盖 ≥80%（技能栏堆砌无效，要出现在经历句里） |
| 结构 | 标准节名（工作经历/教育/技能）；不用表格排版整页（解析易碎） |
| 联系方式 | 纯文本行，不放在页眉页脚（部分 ATS 丢页眉） |
| 日期 | 统一 YYYY.MM，倒序 |

### 4.5 配套文档模板

**求职信三段**：为什么是你们（提该公司一个具体事实）→ 为什么是我（2 个最强量化点，对应 JD 要求）→ 下一步（主动约时间，一句话）。≤200 字。

**面试跟进邮件**：24h 内发；谢意一句 + 面试中一个具体讨论点的延伸（证明在听）+ 补充材料链接。≤120 字。

## §5 常见翻车表

| 翻车 | 根因 | 修法 |
|---|---|---|
| extract_text 全空 | 扫描件 | §1 判层 → §3 OCR |
| 表格数字错位 | 无线框表格 stream 模式猜列 | 换线框参数或人工核对；关键报表不允许自动直出 |
| 合并后页码/目录失效 | pypdf 不重建 outline | `w.add_outline_item()` 重建，或书签本来就是链外的就放弃并注明 |
| reportlab 中文方块 | 未注册中文字体 | `registerFont(TTFont(...))` 全局注册后再用 |
| 简历投出去没回音 | 文本层正常但关键词不对齐 | §4.4 关键词项重过；用 §1 抽取自己的简历模拟 ATS 视角 |
