# SeaLeap 欧洲高低客单广告盈利策略

把高客单的决策、信任与售后成本，以及低客单的获客、组合与周转放进同口径利润模型，再安排广告。

## 输入

各站 SKU/ASIN、实际价格与币种、品类价格分布、订单贡献、退货/质保与固定合规成本、决策周期、库存周转、消费者意图、品牌素材与广告/AMC 资格。

## 工作流

1. 依据品类价格分布、决策成本和单位经济分层，不只按 €50。高客单、标准化、季节性等属性分别记录。
2. 分国家核对需求、竞争、本地化、履约和适用品类合规；材料中的核心/增速/新兴站顺序只作为待验证的路线。
3. 高客单重点验证功能与品牌信任、长尾搜索、视频演示及再触达；是否采用固定出价、SB 或 SD 由实际资格和结果决定。
4. 低客单重点核算 CPC/CVR 导致的订单获客成本、多件装的真实贡献和库存周转。低售价不自动意味着复购或适合广泛词。
5. 计算广告前贡献和广告后利润。区分 SP 内部比例、广告产品比例和国家比例，最终换算为金额并核对总上限。普通广告组不能被赋予不存在的独立日预算。
6. 选择一个站点/流量/素材/受众主变量测试，记录归因成熟期与退出条件。跨站复制时重新审核商品、语言、币种与当地预算。

## 交付

SKU 分层、国家适配矩阵、广告前/后利润表、预算层级及金额、关键词与创意路线、受众实验、库存与售后护栏。

## 证据与执行范围

- 材料中的案例、比例和时间表标为 `COURSE_BASELINE` 或 `TRAINING_CASE`；来源与口径已核验的店铺数据标为 `ACCOUNT_FACT`，用户转交但未核验的数据标为 `USER_PROVIDED`，合成练习标为 `SIMULATED`。推断标为 `HYPOTHESIS`，缺失项写 `UNKNOWN`，不补成 0。
- 先固定店铺、广告 profile、站点、ASIN、币种、数据窗口与归因口径。课程介绍的资格、界面、报告字段和功能覆盖在实际使用时核验。
- 默认交付诊断与草案。真实写入只在当前会话已授权的对象、动作和预算内执行，并保存旧值与回读结果；新增范围先取得授权。
