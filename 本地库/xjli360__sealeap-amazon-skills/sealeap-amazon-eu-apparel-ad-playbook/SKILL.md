# SeaLeap 欧洲服饰生命周期投放实战

先解决服饰的真实适配、信任与退货，再按产品类型和阶段选择广告。材料中的曝光目标不能覆盖利润与库存边界。

## 输入

国家/币种、ASIN/变体、材质与洗护证明、尺码/版型、价格/促销、库存和退货、销售趋势、广告及总销售、品牌/创意/AMC 资格和预算上限。

## 工作流

1. 根据需求曲线区分长青、短周期和季节性，标记销售中断与新品竞争。按真实证据判断当前阶段，不机械使用三年或三个月阈值。
2. 检查消费者购买问题：材质、版型、工艺、价格、礼赠和售后。声明如全棉、不缩水、透气必须回到产品证据；同时提供适用单位与准确尺码。
3. 新品用相关长尾、自动探索与有资格的品牌创意测试，保留损失上限。不得按课件总结“不看 CVR/ROAS，只看曝光”。
4. 成长时从有效长尾扩展到核心意图、商品定向和品牌承接，按实际库存与贡献验证是否扩大；样本不足的 7 天零单不能自动否定。
5. 成熟时评估品牌防守、季节款/真实变体、复购和受众。AMC 是分析/受众工具，其实验预算应落入实际承接 campaign，不能作为与 SP/SB 平行的额外广告费用再加一遍。
6. 对每次页面、价格、素材、关键词或受众改变单独记录。阶段成功应同时满足数据成熟、利润和库存条件。

## 交付

国家及品类适用性、生命周期诊断、材质/尺码/页面证据清单、阶段预算与触点、受众定义、试验和退出条件。

## 证据与执行范围

- 材料中的案例、比例和时间表标为 `COURSE_BASELINE` 或 `TRAINING_CASE`；来源与口径已核验的店铺数据标为 `ACCOUNT_FACT`，用户转交但未核验的数据标为 `USER_PROVIDED`，合成练习标为 `SIMULATED`。推断标为 `HYPOTHESIS`，缺失项写 `UNKNOWN`，不补成 0。
- 先固定店铺、广告 profile、站点、ASIN、币种、数据窗口与归因口径。课程介绍的资格、界面、报告字段和功能覆盖在实际使用时核验。
- 默认交付诊断与草案。真实写入只在当前会话已授权的对象、动作和预算内执行，并保存旧值与回读结果；新增范围先取得授权。
